# RuleCanvasKit v0.7.0 — Workbench Ergonomics, Accessibility, and Motion

RuleCanvasKit `v0.7.0` refines the AgentGate and InterlockSim browser workbenches with a shared visual design system (`DESIGN.md`), persistent Light/Dark/System theming, fixed-viewport multi-pane layouts, a compact AST expression and schema editor, custom accessible select menus, Escape-dismissible tooltips, and a restrained 90–280 ms motion layer.

The underlying verification core (`@rulecanvas/core`), shared UI formatters and replay controller (`@rulecanvas/ui`), and worker transport / portable JSON codec (`@rulecanvas/workbench`) are unchanged from `v0.5.0`. All verification algorithms, model semantics, verdict conditions, and educational non-certification disclosures remain intact.

## Release Highlights

- **Shared Design System & Themes**: Unified OKLCH color, surface, border, typography, and spacing tokens (`DESIGN.md`) with persistent `System`, `Light`, and `Dark` theme switching (`useWorkbenchTheme`, `WorkbenchThemeSwitch`) and self-hosted IBM Plex Sans / IBM Plex Mono WOFF2 subsets (zero external CDN requests).
- **Fixed-Viewport Workbench Ergonomics**:
  - **AgentGate**: Three-pane desktop workspace with independently scrolling rule navigator, focused rule/guard/update AST editor, compact schema table (stacking cleanly below `480px` container width), and tabbed verification inspector.
  - **InterlockSim**: Pinned discrete BSL-3 airlock schematic paired with a scrolling operator console and tabbed trace, state, and guard inspection.
- **Custom Controls & Discoverability**:
  - `WorkbenchSelect` (`@rulecanvas/workbench-react`): WAI-ARIA APG select-only combobox replacing every native `<select>` in both workbenches, rendered in the browser top layer (`popover="manual"`) with viewport clamping/flipping, full keyboard navigation, type-ahead, and draggable scrollbars.
  - `VerificationBoundsControl` and `WorkbenchGuideControl`: On-demand disclosure popovers keeping the command header compact across desktop and small-laptop widths (`1024–1279px`).
  - `useWorkbenchTooltips`: Viewport-clamped, Escape-dismissible decorative tooltips for icon-only controls and the `Ctrl/Cmd + Enter` shortcut.
- **Restrained Motion & Reduced-Motion Support**: One 90–280 ms motion scale without overshoot across tab indicators, panels, AST groups, menus, schematic travel, and changed replay values, disabled under `prefers-reduced-motion: reduce`.

## Verification Summary

Release checks validate:

- Workspace builds (`pnpm build`), typechecks (`pnpm typecheck`), and strict per-library `tsc --noEmit` checks across all four libraries.
- Unit, property-based (`FC_SEED=918273645`), architecture boundary (`pnpm verify:boundaries`), shared-UI parity (`tests/shared-ui-parity.test.ts`), test hygiene (`pnpm verify:hygiene`), and release-preflight (`pnpm test:release:preflight`) suites.
- Pure Node ESM export checks (`pnpm verify:exports`), map-free tarball allowlist and offline third-app booking consumer checks (`pnpm verify:pack`), and the deterministic benchmark suite (`pnpm bench`).
- Headless Chromium E2E tests (`pnpm test:browser`) across desktop, small-laptop, tablet, and mobile viewports (`360–1440px`) in Light and Dark themes, including keyboard interaction checks, reduced-motion checks, zero external font/network requests, and automated `axe-core` WCAG 2.x A/AA rule checks across audited states.

## Known Limitations

- **Automated accessibility checks are not a substitute for full WCAG compliance**: Passing automated `axe-core` WCAG 2.x A/AA rules and Playwright keyboard/focus tests does not by itself establish full WCAG 2.2 AA conformance; manual screen-reader (VoiceOver/NVDA/JAWS) and assistive-technology testing across browsers remains recommended.
- **Model-scoped verification only**: Verdicts apply strictly to the declared finite-state model, exploration bounds (`maxStates`, `maxDepth`), and explicit `ModelAssumption[]` assumptions.
- **Educational & design-time scope**: AgentGate models approval policies at design time (not a live runtime firewall). InterlockSim is an educational discrete-state simulator only — not certified for IEC 61508 / SIL or physical safety-critical control.
- **Private workbench packages**: `@rulecanvas/workbench` and `@rulecanvas/workbench-react` remain `"private": true` workspace packages verified via local tarballs (`pnpm verify:pack`).
