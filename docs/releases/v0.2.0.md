- **Target version**: `v0.2.0` (`@rulecanvas/ui@0.2.0`; `@rulecanvas/core` remains at `0.1.0`)

## 1. Shared Expression and State Formatters

[`packages/rulecanvas-ui/src/format.ts`](../../packages/rulecanvas-ui/src/format.ts) provides total, deterministic formatting utilities for models, schemas, guards, updates, and state snapshots:

- **Public exports**:
  - `formatStateValue(value: StateValue): string`
  - `formatVarDef(def: VarDef): string`
  - `formatValueExpr(expr: ValueExpr): string`
  - `formatBoolExpr(expr: BoolExpr): string`
  - `formatUpdateAssignment(update: UpdateAssignment): string`
  - `formatRuleSummary(rule: TransitionRule): FormattedRuleSummary` (returns a deeply frozen `{ id, label, guardText, updatesText }` summary)
- **Normalization and unambiguous quoting**:
  - **`-0` normalization**: `formatStateValue` normalizes `-0` to `'0'`, renders safe integers and booleans deterministically, JSON-escapes string values, and maps non-safe integers (`1.5`, `NaN`, etc.) or invalid values to `'<invalid>'`.
  - **JSON-quoted enum members**: `formatVarDef` formats boolean variables as `'boolean'`, integer bounds (normalizing `-0`, requiring safe integers with `min <= max`) as `'int [min..max]'`, and enum definitions as `'enum ("a" | "b")'` using `JSON.stringify` on every member so strings containing `|` or quotes never collide.
  - **Backtick variable quoting**: Variables matching `/^[A-Za-z_][A-Za-z0-9_]*$/` outside reserved expression keywords (`true`, `false`, `in`, `and`, `or`, `not`) render bare; reserved keywords and special variable names (such as `true`, `0`, `a + b`, ``a`b``, or `""`) are backtick-quoted with escaped inner characters so variable references never collide with literals or operators.
- **Minimal precedence parenthesization**:
  - Value expressions (`add`, `sub`) parenthesize right-hand `add`/`sub` operands under `sub` (for example, `a - (b + c)` and `a - (b - c)`) while leaving left-associative forms (`a - b + c`, `a - b - c`, `a + b - c`) unparenthesized.
  - Boolean expressions follow exact precedence `or` (`0`) `<` `and` (`1`) `<` comparisons/`in` (`2`) `<` `not` (`3`) `<` atoms (`4`): single-argument `and`/`or` unwraps to child precedence, empty `and`/`or` formats as `'true'`/`'false'`, `or` inside `and` is parenthesized (`(a || b) && c`), `and` inside `or` stays flat (`a && b || c`), and `not` wraps lower-precedence compound operands (`!(a == b)`, `!(a && b)`, `!(x in ["a", "b"])`).
- **Bounded traversal**: Formatting walks enforce `MAX_FORMAT_DEPTH = 64` and `MAX_FORMAT_VISITS = 512` and catch malformed, cyclic, accessor, or `Proxy`-trapped inputs, returning `'<invalid>'` (or a frozen `<invalid>` `FormattedRuleSummary`) without throwing.

## 2. Verification Verdict Visualization

[`packages/rulecanvas-ui/src/components.ts`](../../packages/rulecanvas-ui/src/components.ts) provides `buildVerdictSummaryView(result: VerifyResult): VerdictSummaryView` and `renderVerdictSummaryHtml(result: VerifyResult): string` covering every verification outcome:

- **`VERIFIED`**:
  - Emits `badge: 'VERIFIED'`, `symbol: '✓'`, `tone: 'success'`, `role: 'status'`, `vacuousGoalWarning: false`, and renders `Goal reachable: Yes` (`data-goal-status="reachable"`) when `goalReachable: true` or omits goal reachability when no goal is declared.
  - **Vacuous-fix detection**: When `goalReachable: false`, emits `badge: 'VERIFIED (GOAL UNREACHABLE)'`, `symbol: '!'`, `tone: 'warning'`, `role: 'status'`, `vacuousGoalWarning: true`, `Goal reachable: No` (`data-goal-status="unreachable"`), and sets `data-vacuous-goal="true"` on the rendered `<section class="rc-verdict">` so vacuous fixes cannot masquerade as healthy passes.
- **`VIOLATED`**:
  - Emits `badge: 'VIOLATED'`, `symbol: '✗'`, `tone: 'danger'`, `role: 'alert'`, reports step counts (`'Initial state violates one or more declared invariants.'` when `traceLength === 0`, or `'Counterexample found in N step(s).'`), and lists every violated invariant ID from `violatedInvariantIds`.
  - Enforces partial-exploration goal semantics by rejecting `goalReachable: false` (since encountering a violation early does not prove goal unreachability).
- **`INCONCLUSIVE`**:
  - Emits `badge: 'INCONCLUSIVE'`, `symbol: '…'`, `tone: 'warning'`, `role: 'status'`, validates `reason` (`'MAX_STATES' | 'MAX_DEPTH'`), `completedDepth`, and non-negative safe-integer `frontierRemaining`, and renders `<dl class="rc-inconclusive-meta">`.
  - Rejects `goalReachable: false` on `INCONCLUSIVE` results while allowing omitted `goalReachable` or `goalReachable: true` when a goal was witnessed before truncation.
- **`INVALID`**:
  - Emits `badge: 'INVALID'`, `symbol: '!'`, `tone: 'error'`, `role: 'alert'`, reporting `errorCount` and the first validation error message, and serves as the fail-closed fallback for any malformed or untrusted `VerifyResult` payload.
- **Verification statistics**: Formats `theoreticalStates`, `statesExplored`, `transitionsEvaluated`, `maxDepthReached`, and `deadlockStatesFound` into `<dl class="rc-stats">`.

## 3. Counterexample Replay

[`packages/rulecanvas-ui/src/replay-controller.ts`](../../packages/rulecanvas-ui/src/replay-controller.ts) builds immutable replay sessions backed directly by `@rulecanvas/core` (`validateModel`, `getInitialState`, `replayTrace`, `getEnabledTransitions`) so traces never diverge from verifier semantics:

- **`createTraceReplaySession(model, ruleIds)`**:
  - Validates the model, deep-clones and deep-freezes it, captures `ruleIds` via a single own-descriptor snapshot (up to `MAX_REPLAY_STEPS = 10_000`, rejecting sparse holes with `INVALID_TRACE`, accessors with `INVALID_ACCESSOR_PROPERTY`, and oversize inputs with `TRACE_TOO_LONG`), and replays via `replayTrace`.
  - On failing rule sequences, returns `stepIndex`, frozen diagnostics (`error` and `errors`), and valid prefix `completedSteps`.
- **`createVerdictReplaySession(model, result, options?)`**:
  - Supports `options: VerdictReplayOptions` (`{ startAt?: 'initial' | 'terminal' }`, rejecting invalid options with `INVALID_REPLAY_OPTIONS`).
  - For **`VIOLATED`** verdicts (including zero-step `s0` violations), replays `result.trace` against the model and verifies every step's `ruleId`, `stateBefore`, `stateAfter`, and `changedVars`, as well as `terminalState`, `violatedInvariantIds`, and optional `goalReachable`, returning `VERDICT_MODEL_MISMATCH` on any mismatch with the supplied model. `startAt: 'initial'` positions the cursor at step `0`, while `startAt: 'terminal'` opens directly at `cursor === totalSteps`.
  - For **`VERIFIED`** and **`INCONCLUSIVE`** verdicts, initializes a `'manual'` simulation session at `s0` while validating that `s0` does not violate invariants or contradict `goalReachable` (`VERDICT_MODEL_MISMATCH`), and rejecting `goalReachable: false` on `INCONCLUSIVE` (`INVALID_VERIFY_RESULT`).
  - For **`INVALID`** verdicts, returns a failure result propagating the original `errors` and any valid prefix `completedSteps` salvaged from `result.trace`.

## 4. Manual Simulation Controls

[`packages/rulecanvas-ui/src/replay-controller.ts`](../../packages/rulecanvas-ui/src/replay-controller.ts) provides immutable session navigation and step-by-step manual simulation controls:

- **Initialization and navigation**:
  - `createManualSimulationSession(model)` opens a `'manual'` session at `s0` with computed `enabledTransitions`, `violatedInvariantIds`, and optional `goalReached`.
  - `stepReplayForward(session)`, `stepReplayBackward(session)`, and `jumpReplayToStep(session, stepIndex)` validate both canonical (`WeakSet`-tracked) and externally constructed session objects (`INVALID_SESSION` on inconsistent snapshots or history) and reject non-safe-integer or out-of-range step indices without clamping (`INVALID_STEP_INDEX`).
  - `resetReplaySession(session)` returns to `cursor = 0` while preserving `steps` in `'trace'` mode and clearing `steps` in `'manual'` mode.
- **Manual execution and history branching**:
  - `applyManualStep(session, ruleId)` executes via `@rulecanvas/core`'s `stepModel`, surfacing deterministic core error codes (`RULE_DISABLED`, `UNKNOWN_RULE`, `OUT_OF_DOMAIN_TRANSITION`) alongside the unchanged canonical frozen `session`, and enforcing `MAX_REPLAY_STEPS` (`TRACE_TOO_LONG`).
  - Stepping backward (or jumping earlier in a `'trace'` or `'manual'` session) and calling `applyManualStep` branches cleanly from `steps.slice(0, cursor)`, truncating the discarded suffix and switching the resulting session to `'manual'` mode.

## 5. Accessible Semantic Renderers

[`packages/rulecanvas-ui/src/components.ts`](../../packages/rulecanvas-ui/src/components.ts) exports framework-independent view builders and semantic HTML renderers alongside `escapeHtml`:

- **State table**: `buildStateTableView(model, state, changedVars?)` and `renderStateTableHtml(model, state, changedVars?)` emit `<table class="rc-state-table">` with `aria-label`, `<th scope="col">` headers (`Variable`, `Domain`, `Value`, `Change`), JSON/formatted values, and `Modified` (`*`) / `Unchanged` (`·`) badges.
- **Invariants and goal panel**: `buildInvariantsPanelView(model, violatedInvariantIds, goalReached?)` and `renderInvariantsPanelHtml(model, violatedInvariantIds, goalReached?)` render each invariant with `PASS` (`✓`) or `VIOLATED` (`✗`) badges, formatted expressions, and optional goal state (`REACHED` `✓`, `NOT REACHED` `○`, or `NOT EVALUATED` `?`).
- **Replay timeline and transition controls**: `renderReplayTimelineHtml(session)` renders `<nav class="rc-replay-controls" aria-label="Trace replay controls">` with `<button type="button">` actions (`reset`, `step-back`, `step-forward`, `apply-rule`), explicit `disabled` states, a live step counter (`role="status" aria-live="polite"`), `<ol class="rc-trace-list">` marking the active step with `aria-current="step"`, variable value diffs (`before -> after`), and `ENABLED` (`✓`) / `DISABLED` (`×`) rule guard listings.
- **Assumptions and validation errors**: `renderAssumptionsPanelHtml(assumptions)` renders the explicit discrete-model verification scope notice alongside category badges and `notModeled` disclosures; `renderValidationErrorsHtml(errors)` renders structured error code, path, and message lists inside `role="alert" aria-live="assertive"`.
- **Non-color-only communication**: All status states combine explicit text badges, `data-status` attributes, and decorative (`aria-hidden="true"`) symbols rather than relying on color alone.

## 6. Input Validation and Security Hardening

All `@rulecanvas/ui` modules treat caller inputs as untrusted and build on internal descriptor-safe utilities in [`packages/rulecanvas-ui/src/safe-input.ts`](../../packages/rulecanvas-ui/src/safe-input.ts):

- **Own-descriptor inspection without getter execution**: `isPlainObject`, `readOwnDataProp`, `readSafeArray`, and `readOwnStringArray` check `Object.getOwnPropertyDescriptor` directly, rejecting non-plain objects, own getter/setter accessors, symbol keys, sparse holes, and out-of-bounds lengths (`MAX_SAFE_ARRAY_LENGTH = 100_000`, `MAX_REPLAY_STEPS = 10_000`) without triggering property getters or custom array traps.
- **Prototype pollution defense**: Inherited properties on `Object.prototype` (such as `goal`, `goalReachable`, and `goalReached`, including inherited getters) are ignored via own-property checks (`readOwnDataProp` / `Object.hasOwn`).
- **Isolated frozen outputs**: `cloneAndFreezeSnapshot` and `deepCloneAndFreezeModel` clone models and flat primitive snapshots using `Reflect.ownKeys` and own enumerable data descriptors (`MAX_AST_CLONE_DEPTH = 64`), normalizing `-0` to `0` and deep-freezing results so later caller mutations cannot alter active sessions.
- **Fail-closed invalidation (no fabricated healthy status)**: Malformed, null, or nested-accessor expressions in invariants, goals, schema `VarDef` entries, or rule guards, as well as invalid `violatedInvariantIds`, `goalReached`, `changedVars`, or inconsistent timeline coordinates, return `INVALID` / alert markup (`role="alert"`) or `<invalid>` fallbacks instead of fabricating `PASS`, `REACHED`, or `Unchanged`.
- **XSS and trap containment**: `escapeHtml` escapes `&`, `<`, `>`, `"`, and `'` across all rendered HTML text and attributes, and all public functions catch `Proxy` trap exceptions cleanly rather than throwing uncaught errors.

## 8. Known Limitations

- **No DOM runtime, event bindings, or CSS layer**: `@rulecanvas/ui` (`v0.2.0`) delivers framework-independent view-model builders, formatters, static HTML-string renderers (`render*Html`), and an immutable replay/simulation controller. It does not bundle DOM mounting, framework components, stylesheets, or live browser event wiring.
- **Browser, keyboard, and screen-reader QA deferred to app workbenches**: Accessibility semantics are verified via HTML-string and view-model unit tests; interactive keyboard navigation, focus management, visual layout, and screen-reader verification remain to be performed once interactive browser workbenches are built in `apps/` (beginning with AgentGate in `v0.3.0`).
- **Bounded discrete-state and assumption scope**: All verification, replay, and simulation guarantees hold strictly within declared bounded finite-state models (`maxStates <= 100,000`, `maxDepth <= 10,000`, `MAX_REPLAY_STEPS = 10,000`) and their explicit `ModelAssumption[]` declarations. RuleCanvasKit does not claim real-world security guarantees, live production policy enforcement, or physical safety certification.
- **Maintainer tag pending**: These release notes are prepared for `v0.2.0`; creating and pushing the `v0.2.0` Git tag and publishing the GitHub Release remain maintainer actions.
