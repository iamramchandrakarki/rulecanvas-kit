# RuleCanvasKit v0.8.0 — Static Hub, Starter Template, Deterministic Audit Reports, and CLI Gate

RuleCanvasKit `v0.8.0` delivers two cohesive milestones on top of the unchanged `@rulecanvas/core` (`v0.1.0`) verification engine:

1. **Skeleton Crew Hub & Standalone Starter (`site/`, `templates/workbench-starter/`)**: A portable static landing hub linking both workbenches via relative URLs, `WorkbenchBrandLink` return navigation with discard protection, a standalone CI/CD release-gate React starter template installed from local tarballs (`pnpm run pack:local`), and extended `verify:pack`, `release-preflight`, boundary, and hygiene gates.
2. **Deterministic Audit Reports, Verdict Deltas, Hardened Transport, and CLI (`report.ts`, `delta.ts`, `check-model.mjs`, `ExportReportMenu`, `VerdictDeltaRow`)**: Provenance-tagged JSON and Markdown verification reports, same-model before/after verdict delta analysis, allowlisted worker result reconstruction, strict duplicate-key JSON rejection across both apps, a `pnpm check:model` CLI gate, and responsive replay/popover polish.

## Release Highlights

- **Static Hub & Brand Return Navigation (`site/`, `WorkbenchBrandLink`)**:
  - `site/` provides a zero-CDN, portable landing page with synchronized `System` / `Light` / `Dark` theming and relative preset links into AgentGate and InterlockSim (verified against `verifyModel` in `tests/site-hub.test.ts` and packaged as `site-static.tar.gz`).
  - `WorkbenchBrandLink` connects each workbench's brand mark back to `../` (or `VITE_HUB_URL`) while honoring the unsaved-edits discard guard.
- **Standalone Starter Template (`templates/workbench-starter/`)**:
  - Models a CI/CD production release gate (`broken` vs. `principled`) using all four RuleCanvasKit packages installed from local tarballs written by `pnpm run pack:local`, including non-stale `validated-snapshot` report export (`Copy Markdown`, `Download Markdown`, `Download JSON`) and `node --test` model verification tests.
  - `pnpm verify:pack` copies, installs offline, typechecks (`NodeNext` and `Bundler`), builds with Vite, and tests the starter template; `pnpm test:browser` checks both variants in worker mode when `STARTER_FIXTURE_DIST` is set.
- **Deterministic Verification Reports & Verdict Deltas (`@rulecanvas/ui`, `@rulecanvas/workbench-react`)**:
  - `report.ts` (`VERIFICATION_REPORT_SCHEMA_VERSION = '1.0.0'`) builds deeply frozen, `WeakSet`-tracked `VerificationReport` payloads with explicit provenance (`'validated-snapshot'` vs. `'recomputed-core'`), decimal-string `BigInt` state counts, vacuous-goal warnings, and deterministic Markdown/JSON serializers.
  - `delta.ts` (`computeVerdictDelta`) classifies before/after runs on the same model (`repaired`, `verified-with-spec-change`, `vacuous-lockout`, `inconclusive-after-violation`, `still-violated`, `regression`, `unchanged`, `contradictory`, `other`) while distinguishing rule edits from spec/bound changes. Cosmetic metadata edits (model name, rule/invariant/goal ids and labels) are not semantic changes, `repaired` requires an actual rule change, and contradictory verdicts for identical semantic inputs and bounds are reported as a `contradictory` integrity failure rather than a repair.
  - `ExportReportMenu` and `VerdictDeltaRow` surface these capabilities in both AgentGate and InterlockSim.
- **CLI Model Checker (`scripts/check-model.mjs`)**:
  - `pnpm check:model <model.json> [--markdown] [--max-states <int>] [--max-depth <int>] [--allow-vacuous]` decodes saved model JSON with strict duplicate-key rejection, runs `verifyAndBuildReport` (`recomputed-core` provenance, default `maxStates: 10_000`, `maxDepth: 100`), and exits `0` only for non-vacuous `VERIFIED` (unless `--allow-vacuous` is set), `1` for `VIOLATED`/`INCONCLUSIVE`/runtime `INVALID`/vacuous `VERIFIED`, and `2` for CLI/JSON decode errors.
- **Hardened Transport, Strict App Imports & Workbench UX**:
  - `@rulecanvas/workbench/verify` (`sanitizeAndFreezeVerifyResult`) reconstructs `VerifyResult` objects from allowlisted fields, checks `stats.theoreticalStates` via exact `BigInt` multiplication, and verifies counterexample/runtime traces via `@rulecanvas/core` `replayTrace` / `stepModel`.
  - Both AgentGate (`apps/agent-gate/src/model-editor.ts`) and InterlockSim (`apps/interlock-sim/src/model-inspector.ts`) now enforce `duplicateKeys: 'reject'` under `DEFAULT_MODEL_JSON_LIMITS` (512,000 chars / 10,000 nodes) and configure `asyncStartupError: 'report'`.
  - InterlockSim gains an inline trace toolbar (`Reset`, `Previous`, `Next`, `Restore Counterexample`); both apps add `[` and `]` replay step shortcuts, `.rc-scroll-x` horizontal scroll cues with a sticky `Action` column on comparison tables, viewport-clamped `WorkbenchGuideControl` placement, and a fixed-position ancestor-compensation fallback in `WorkbenchSelect` when Popover API is unavailable.

## Verification Summary

Release checks validate:

- Workspace builds (`pnpm build`), workspace typechecks (`pnpm typecheck`), and strict per-library `tsc --noEmit` checks across all four libraries.
- Pure Node ESM export checks (`pnpm verify:exports`), map-free tarball allowlists and offline starter template consumer verification (`pnpm verify:pack`), and CLI regression tests (`pnpm test:cli`).
- Unit, core property-based (`FC_SEED=918273645`), UI report/delta property-based (`FC_SEED=918273645`), architecture & overclaim boundary (`pnpm verify:boundaries`), shared-UI parity, anti-skip hygiene (`pnpm verify:hygiene`), release-preflight (`pnpm test:release:preflight`), and deterministic benchmark (`pnpm bench`) suites.
- Headless Chromium E2E tests (`pnpm test:browser`) across desktop, small-laptop, tablet, and mobile viewports (`360–1440px`) in Light and Dark themes, covering AgentGate, InterlockSim, the static hub under `/` and `/rulecanvas-kit/`, and the packed starter template in worker mode.

## Known Limitations

- **Model-scoped verification only**: Verdicts apply strictly to the declared finite-state model, exploration bounds (`maxStates`, `maxDepth`), and explicit `ModelAssumption[]` assumptions.
- **Educational & design-time scope**: AgentGate evaluates discrete permission and approval policies at design time (it is not a live runtime firewall or production scanner). InterlockSim is an educational discrete-state simulator only — not certified for IEC 61508 / SIL or physical safety-critical control.
- **Automated accessibility checks are not a full WCAG audit**: Passing `axe-core` WCAG A/AA checks and Playwright keyboard tests does not replace manual assistive-technology testing across browsers.
- **Private workbench packages**: `@rulecanvas/workbench` and `@rulecanvas/workbench-react` remain `"private": true` workspace packages verified via local tarballs (`pnpm verify:pack`, `pnpm run pack:local`).
- **Kiro Spec 1 hook confirmation**: As recorded in `.kiro/specs/skeleton-crew-hub-and-starter/tasks.md`, Task 2.1 (confirming automatic file-save firing of `.kiro/hooks/verify-boundaries.json`) remains open; `pnpm verify:boundaries` is run explicitly locally and in CI.
