# RuleCanvasKit v0.4.0 — InterlockSim

InterlockSim is an interactive browser workbench for exploring discrete airlock interlocks. It demonstrates how a sequence of individually permitted actions can violate an invariant, and how a repair can satisfy the invariants while also blocking the intended goal.

## Try the workbench

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm --filter @rulecanvas/interlock-sim dev
```

1. Open the broken preset and run verification. Replay the six-step counterexample to see which state first violates an invariant.
2. Inspect a rule's guard or use the guided repair on the built-in broken preset. Run verification again to check the repaired model and its goal under the current bounds.
3. Open the comparison matrix. The vacuous preset satisfies the invariants in its reachable state space while leaving the declared goal unreachable.

The operator console lets you advance through enabled transitions and inspect why other actions are blocked. You can import or export a finite-state model as JSON. The editor rejects invalid integer drafts and unsafe or out-of-budget JSON and surfaces validation errors at the point of use.

## Understand a result

Every verdict belongs to the exact model snapshot, exploration bounds, and assumptions used for that run. Edits mark older results as out of date. Verification runs in a Web Worker when available, with a main-thread fallback. If exploration reaches a bound before completing, the result is **INCONCLUSIVE**. A completed verification establishes a result about the declared finite-state model and its assumptions.

InterlockSim is an educational simulator. It omits continuous physics, hardware timing, and sensor failure modes. It is unsuitable for real-world control, containment decisions, or safety certification.
