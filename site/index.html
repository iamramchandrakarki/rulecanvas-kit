Rules that look sound individually fail when they compose across transitions.

RuleCanvasKit explores every reachable state of a finite rule model, within the bounds you set, and replays the shortest path to the first broken invariant. Pick a workbench and watch it happen.

Four packages, one direction

Each layer depends only on the layers above it. The verifier knows nothing about agents, airlocks, or browsers. The two workbenches add the domain on top.

  1. @rulecanvas/core

    Validates a model, runs bounded breadth-first verification, and replays traces. Pure ES2022 with no runtime dependencies.

  2. @rulecanvas/ui

    Formats verdicts and drives step-by-step trace replay. Depends on core only.

  3. @rulecanvas/workbench

    Strict model JSON codec and worker or main-thread verification transport. Depends on core only.

  4. @rulecanvas/workbench-react

    React adapters for verification snapshots, verdict summaries, navigation, and themes. React is a peer dependency.

  5. AgentGate and InterlockSim

    Two static Vite apps under apps/ that supply the scenarios and the interface.

Start from the template

The Skeleton Crew Starter Template is a small React workbench for a CI/CD production release gate. Its broken variant lets a hotfix bypass reach production unreviewed. Its principled fix reaches stage == "prod" only after review. It installs from local package tarballs, outside this repository.

From the repository root, run pnpm check:model on any saved model JSON to emit a recomputed-core JSON or Markdown report. Vacuous passes exit non-zero unless --allow-vacuous is set.

Read the template README

Shell — Starter template 
git clone https://github.com/iamramchandrakarki/rulecanvas-kit.git
cd rulecanvas-kit
pnpm install
pnpm run pack:local          # writes ../rulecanvas-tarballs/*.tgz
cp -R templates/workbench-starter ../my-workbench
cd ../my-workbench
pnpm install
pnpm test                    # node --test tests/
pnpm build                   # vite build into dist/

Shell — Model CLI 
pnpm run build:libs
pnpm check:model model.json
pnpm check:model model.json --markdown
pnpm check:model model.json --allow-vacuous

What a verdict covers

A result describes the model you wrote, not the system it stands for.

VERIFIED
Every reachable state of the declared finite model, within the state and depth bounds, satisfied every invariant. Anything listed under assumptions as not modeled is outside the result.
VIOLATED
The checker found the shortest sequence of rule firings that reaches a state breaking an invariant. You can replay it step by step.
INCONCLUSIVE
A state or depth bound was reached first. This is not a pass. Raise the bounds or shrink the model.
INVALID
The model failed validation, so nothing was explored.

What RuleCanvasKit is not

  • It is not a runtime firewall, policy enforcement point, or agent sandbox. Nothing here intercepts live requests, tool calls, or credentials.
  • InterlockSim is an educational simulation. It has no IEC 61508 or SIL certification and must never control laboratory equipment.
  • The checker runs in your browser or in Node. It sends no model data to a server.
